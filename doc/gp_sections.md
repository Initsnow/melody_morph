# gp-sections：自动分段

`gp-sections` 从 Guitar Pro 文件自动检测歌曲段落，并把结果写回 GP 的段落标记
（`<Section>`，格式与《春日影.gp》一致：Letter + Text，如 `A:Part 1`；
所有段落都带字母，不产生空 Letter）。

## 用法

```bash
# 写回 <原名>_sections.gp（原文件不变；已有段落的小节默认跳过）
uv run gp-sections "song.gp"

# 只预览候选边界与触发证据（推荐先看再写回）
uv run gp-sections "song.gp" --no-write

# 指定轨道 / 人声轨 / 覆盖已有段落 / 输出 JSON
uv run gp-sections "song.gp" --track "Rhythm Guitar" --overwrite --out sections.json
uv run gp-sections "song.gp" --vocal-track "Vocal"
uv run gp-sections "song.gp" --name "A=Verse 1" --name "C=Chorus"
```

## 算法

1. **每小节特征**（自动适配文件里有哪些轨）：

   - 和弦：逐小节识别（复用 gp-chords 管线），token 化为主音罗马度数 + 品质家族；
   - 鼓指纹（16 分桶音色集合，Jaccard 相似）；
   - 贝斯根音；
   - 密度：各非鼓轨总音符时值（最强单特征）；
   - 人声活动度 / 人声平均音高（旋律轮廓，自动识别旋律轨，`--vocal-track` 可覆盖）；
   - 轨道活动组合（哪些轨在响）、闷音比例、和声节奏密度（auto 窗口数）、速度；
   - 硬信号：调号 / 拍号 / 速度变化、全曲编曲级长休止。

2. **边界打分**：每个特征建自相似矩阵 → novelty 曲线（左右块内部相似、跨块
   不相似），归一化后加权求和（密度 ×2、人声 ×1.5、其余 ×1）；另加和弦矩阵的
   **重复起点**曲线——新段落在复用前面某段的材料（如副歌复用 Intro 的进行）时，
   novelty 抓不到，重复起点能抓到。峰选取阈值 = 均值 + 0.4×标准差，每个
   最小间距窗口内取最强局部峰；novelty 允许尾部截断（最后几小节的 Outro
   边界也能检出）。

3. **结构重复规则**：起点向后的块在 ≥16 小节外有 ≥12 小节逐位对齐重复、
   且是"新鲜起点"（上一位置没有长重复）、且有独立佐证（窗口持续变化 /
   某特征 novelty 局部峰 / 硬信号）→ 段落起点。副歌/主歌重复三遍时每遍
   起点都能抓到（《転がる岩》17 小节副歌 ×3 的 39/76/129、《カラカラ》
   的 27/176），段内乐句重复和跨段落和声巧合不会误报。另有**开头复现**
   规则：块与歌曲开头对齐相似 ≥0.75 时是回顾式段落起点。

4. **连续循环切分（有实锤才切）**：周期 ≥ 8 小节的循环在每遍起点是
   **候选**边界，但必须有独立变化实锤才切——轨道活动组合变化（Lead 加入）、
   鼓型变化（逐小节或按循环两半聚合比较）、密度/人声/闷音/和声密度跳变、
   硬信号。光"8 小节重复了两遍"不切：I-V-vi-IV × 8 重复两遍且编曲不变时
   是一整段，不是两个段落。Verse 1/2（25）、Solo 重复（66，鼓聚合变化）、
   Verse 3/4（82，鼓 + 人声旋律变化）都是因为有实锤才被切开的。

5. **段落聚类命名**：段相似度 = 0.7×和弦序列编辑距离 + 0.3×标量特征均值向量
   余弦，长度差超过 2 倍不归同类。贪心聚类：重复段共享字母，Text 用
   `Part N` 区分；首段唯一且短 → `Intro`，末段唯一 → `Outro`（都带字母）；
   `--name` 可覆盖任意字母的文本。

硬信号处理：编曲级长休止仍强制成边界；**调号/拍号/速度变化只作证据**
（段内转调很常见，如《无论如何》Bridge 内部转入 C 大调，强制切开会误伤）。

## 已知边界

实测基准（±2 小节算命中，默认参数）：

- 《无论如何.gp》（用户手动分段 15 个边界）：**15/15 命中，零假阳性**；
  漏不掉任何一段，多出的候选也没有。
- 《春日影.gp》（10 个手工边界）：9/10 命中；漏掉的 45（副歌复用 Intro）
  在自动识别的节奏轨和弦里不复现 Intro 材料（小节 1-2 甚至无和弦），
  属于已知硬边界。
- 《光》RUSANTI-MAN（21 个边界）：18/21 命中，全部命中零假阳性；漏掉的
  是 2~3 小节插段（Interlude/短 Verse）。
- 《カラカラ》（14 个边界）：14/14 命中；多出的候选集中在副歌/前奏内部
  的乐句变化（转谱人没切，但确实有变化）。
- 《転がる岩》（10 个边界）：9/10 命中；副歌 ×3（39/76/129）靠结构重复
  全部抓到，漏掉的是 Outro（146，任何特征都无明显变化）。
- 《光の中へ》（11 个边界）：8/11 命中（12/53/192 漏检）；长副歌
  （53-87，35 小节）内部重复多、两遍副歌开头和声对不齐（重复规则抓到的
  是内部对齐点 61 而不是起点 53），加上 Outro 内部变化，多切了约 10 处。
  这类"长段落内部有真变化"的谱与カラカラ同属特征层面无法区分的情形。

仍区分不了的边界：**小于 2 小节的段落**（如《无论如何》的 2 小节
Pre-Chorus 会被并进相邻段——最小间距/最短段阈值限制）和"和声、编曲都
连续、纯靠歌词或混音细节区分"的边界，这类谱面内容在原理上区分不了。
另外像《春日影》45（副歌复用 Intro）在自动识别的节奏轨和弦里不复现
Intro 材料时也会漏检。
候选边界 + 证据的设计就是让这类情形由人工快速确认，而不是假装全能。
