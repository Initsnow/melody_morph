# gp-sections：自动分段

`gp-sections` 从 Guitar Pro 文件自动检测歌曲段落，并把结果写回 GP 的段落标记
（`<Section>`，格式与《春日影.gp》一致：Letter + Text，如 `A:Part 1`；
所有段落都带字母，不产生空 Letter）。

## 用法

```bash
# 写回 <原名>_sections.gp（原文件不变；已有段落的小节默认跳过）
uv run gp-sections "song.gp"

# 只预览候选边界与触发证据（推荐先看再写回）
uv run gp-sections "song.gp" --no-write

# 指定轨道 / 人声轨 / 覆盖已有段落 / 输出 JSON
uv run gp-sections "song.gp" --track "Rhythm Guitar" --overwrite --out sections.json
uv run gp-sections "song.gp" --vocal-track "Vocal"
uv run gp-sections "song.gp" --name "A=Verse 1" --name "C=Chorus"
```

## 算法

1. **每小节特征**（自动适配文件里有哪些轨）：

   - 和弦：逐小节识别（复用 gp-chords 管线），token 化为主音罗马度数 + 品质家族；
   - 鼓指纹（16 分桶音色集合，Jaccard 相似）；
   - 贝斯根音；
   - 密度：各非鼓轨总音符时值（最强单特征）；
   - 人声活动度 / 人声平均音高（旋律轮廓，自动识别旋律轨，`--vocal-track` 可覆盖）；
   - 轨道活动组合（哪些轨在响）、闷音比例、和声节奏密度（auto 窗口数）、速度；
   - 硬信号：调号 / 拍号 / 速度变化、全曲编曲级长休止。

2. **边界打分**：每个特征建自相似矩阵 → novelty 曲线（左右块内部相似、跨块
   不相似），归一化后加权求和（密度 ×2、人声 ×1.5、其余 ×1；贝斯根音逐小节
   噪声大，默认不参与 novelty 打分）；另加和弦矩阵的**重复起点**曲线——新段落
   在复用前面某段的材料（如副歌复用 Intro 的进行）时，novelty 抓不到，重复起点
   能抓到。峰选取阈值 = 均值 + 0.8×标准差，每个最小间距窗口内取最强局部峰；
   novelty 允许尾部截断（最后几小节的 Outro 边界也能检出）。

3. **结构重复规则**：起点向后的块在 ≥16 小节外有 ≥12 小节逐位对齐重复、
   且是"新鲜起点"（上一位置没有长重复）、且有独立佐证（窗口持续变化 /
   某特征 novelty 局部峰 / 硬信号）→ 段落起点。副歌/主歌重复三遍时每遍
   起点都能抓到（《転がる岩》17 小节副歌 ×3 的 39/76/129、《カラカラ》
   的 27/176），段内乐句重复和跨段落和声巧合不会误报。另有**开头复现**
   规则：块与歌曲开头对齐相似 ≥0.75 时是回顾式段落起点。

4. **连续循环切分（默认关闭，`--split-period` 可开启）**：周期 ≥ 8 小节的
   循环在每遍起点是**候选**边界，但必须有独立变化实锤才切——轨道活动组合变化
   （Lead 加入）、鼓型变化（逐小节或按循环两半聚合比较）、密度/人声/闷音/和声
   密度跳变、硬信号。光"8 小节重复了两遍"不切：I-V-vi-IV × 8 重复两遍且编曲
   不变时是一整段，不是两个段落。实测默认关闭比开启更贴合这批手动标注谱。

5. **段落聚类命名**：段相似度 = 0.7×和弦序列编辑距离 + 0.3×标量特征均值向量
   余弦，长度差超过 2 倍不归同类。贪心聚类：重复段共享字母；首段唯一且短
   → `Intro`，末段唯一 → `Outro`（都带字母）。Text 默认按启发式命名
   （`--naming neutral` 可切回中性的 `Part N`）：反复出现且总长度最长的
   有人声段 → `Chorus`、其余反复有人声段 → `Verse`、紧邻 Chorus 前 →
   `Pre-Chorus`、纯器乐较长 → `Solo`、较短 → `Interlude`、其余 → `Bridge`。
   启发式是"猜"，不保证与转谱人一致（实测 5 首谱的 Chorus/Solo/Pre-Chorus
   大体猜对，个别段会张冠李戴）；`--name` 可逐字母覆盖。

硬信号处理：编曲级长休止仍强制成边界；**调号/拍号/速度变化只作证据**
（段内转调很常见，如《无论如何》Bridge 内部转入 C 大调，强制切开会误伤）。

弱边界后处理：候选边界若同时缺少“短窗持续变化”和“重复支撑”，或分数很低且
证据单一，会被丢弃。这能压掉长段落内部编曲波动造成的假阳性，同时不损失已
确认的重复结构边界。

## 已知边界

实测基准（±2 小节算命中，默认参数；10 首手动标注谱，共 105 个边界）：

- 命中 **81/105**，假阳性 22，漏检 24（F1≈0.78）。
- 表现较好的：Karakara 15/15、High And Dry 10/11、Fake Plastic Trees 6/7。
- 仍容易多切：长段落内部确有编曲变化但转谱人没切分的谱（Weird Fishes、
  光の中へ），这类在特征层面与真实段落很难区分。
- 仍容易漏检：2~4 小节的短过渡段（如 Black Star 的 13/17/32/36、Flashbacker
  的 5/30/42）以及 Ending 类尾段（High And Dry 92）。
- 候选边界 + 证据的设计就是让这类情形由人工快速确认，而不是假装全能。

仍区分不了的边界：**小于 4 小节的短段落**（默认 `--min-bars 4`，更短的
Pre-Chorus/Interlude 会被并进相邻段——最小间距/最短段阈值限制）和"和声、
编曲都连续、纯靠歌词或混音细节区分"的边界，这类谱面内容在原理上区分不了。
另外像《春日影》45（副歌复用 Intro）在自动识别的节奏轨和弦里不复现
Intro 材料时也会漏检。
候选边界 + 证据的设计就是让这类情形由人工快速确认，而不是假装全能。
