# 自动判断调性并写入调号（gp-key）

## 用途

给缺失调号（或调号默认成 C）的 Guitar Pro 文件自动判断调性并写入
`<Key>` 调号；也可用于检查/重估已有文件的调号。输出是新的
`<原名>_key.gp`，原文件不动。

## 原理

1. 用 `gpreader` 解析文件，选取非鼓、有音符的轨道（`--track` 可指定）。
2. 音符按真实时值加权（与和弦识别同一套 `note_weights`），用
   Krumhansl-Kessler 键感轮廓估计调性：对 12 个根音 × 大/小调计算
   与轮廓的相关性，取最高者。
3. 把 (根音, 调式) 映射成 GPIF 的 `<Key>`：升号数为正、降号数为负；
   等音写法取调号较少者（如 Db 而非 C#、G#m 而非 Abm），平局取升号。
   每个 MasterBar 写入/替换 `<Key>`，写回后重新解析自检。

## 行为

默认把估计出的调性写入**全部小节**（覆盖原有调号），输出是新的
`<原名>_key.gp`，原文件不被修改。

- `--per-section`：按段落分组估计（无段落标记的小节用全局估计兜底），
  适合转调谱。
- `--key C` / `--key Am`：直接指定调性，不估计，并写入全部小节。
- `--track`：只用指定轨道估计；`--no-write` 只看结果不写回。

> GP 保存的文件里每个小节都带显式 `<Key>`，从未设置时就是 0 个升降号 + Major，
> 即默认 C 大调——所以"覆盖全部小节"才是脚本的本意。

## 已知限制

- K-K 是概率估计。相对大小调（如 A 大调 ↔ F# 小调）调号相同、只有
  `Mode` 不同，估计可能落到相对小调；旋律/和弦内容越明确，估计越稳。
- 建议先 `--no-write` 看估计结果，不满意用 `--key` 直接指定；
  原文件始终不被修改，可以在 GP8 里对比后再决定是否保留新文件。
